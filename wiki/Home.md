## Keyboard shortcuts (Udemy tab)

| Key | Action |
|-----|--------|
| `D` | Toggle dual captions |
| `S` | Save note + snapshot |
| `J` / `L` | −5s / +5s |
| `[` / `]` | Decrease / increase speed |
| `P` | Picture-in-Picture |

Shortcuts are disabled while typing in an input. Toggle off in **Oynatıcı** tab.
